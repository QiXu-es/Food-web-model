## Generation and analysis of food web based on ecological traits

Analysis code for the manuscript **"Latitudinal  effects on large-mammal food webs during the Early–Middle Pleistocene climate transition"** (Xu, Shen, Erwin *et al.*; corresponding author Junxuan Fan).

#### Data availability

The repository contains **codes and small example data**.

- **Feasible food web generation and analysis** — Includes code for generating predation matrix based on ecological traits and for subsequent network analysis based on matrixs. Named "Feasible web.R".
- **Realised food web generation and analysis** — Includes code for generating realised food web based on predation matrix and for subsequent network analysis. Named "Realised web.R".
- **Original assemblage data from Gongwangling site** — Names and four ecological characters of all taxa. Named "Example - Gongwangling.xlsx".

Inputs:

- **info.csv** — An ecological trait matrix. For "Feasible web.R".
- **feasible.csv** — A predation matrix, replacing taxon names with IDs. For "Realised web.R". Each column displays the predation information for the corresponding taxonomic unit. 0 represents the taxonomic unit that does not prey on the row unit , and 1 represents predation.

Onput:

- **prey.csv** — A predation matrix without taxon names. Generated by "Feasible web.R".

#### How to run

1. Save the compiled ecological information to "info.csv", with each column separated by a space.
2. Run "Feasible web.R" to get the "prey.csv".
3. Add taxon IDs to "prey.csv" and paste the content into "feasible.csv", with each column separated by a space.
4. Run "Feasible web.R" to obtain the analysis results for the feasible web.
5. Run "Realised web.R" to obtain a realised web and its analysis results.
